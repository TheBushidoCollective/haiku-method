Interaction + accessibility

  • Hover: tooltip fades in over 150ms ease. Connector line does not change; dot does not grow (prevents layout shift).
  • Focus: 2px teal-400 outline offset 4px, rounded 4px. Keyboard-reachable via tab; Enter / Space opens the tooltip (is-open class) for sticky inspection.
  • Active: 2s pulse-ring animation on the active iteration only. Respects prefers-reduced-motion — animation disabled, ring stays static.
  • Mobile: tooltip replaced by accordion (details/summary). Active iteration expanded by default. Summary row is 44px min tap target.
  • Collapsed stack (4+ iterations): desktop shows hover-to-peek summary; tap/click expands inline, preserving order. Mobile: earlier iterations rendered as individual collapsible rows (no double-nested collapse).
  • Screen reader: each iteration node has aria-label with number + outcome + triggered_by. The active iteration also gets aria-current="step". The ordered list uses aria-label="Iteration history".
  • Color contrast: all text meets WCAG AA 4.5:1 against surface. State is never carried by color alone — every state also has a label (active / revisited / rollback / hydrated).
  • Empty state (iterations=[] or missing): no crash. Render "Iteration 1 · hydrated" pulled from legacy started_at + the legacy stripe backdrop + inline amber warning (see Variant D).
  • Tooltip positioning: bottom (over the rail) on desktop/tablet; inline expansion on mobile. Tooltip arrow points down at the dot.
  • Feedback_scope chips: each FB-NN chip is clickable → opens the feedback detail drawer (handoff to unit-01/02 feedback panel).

Data binding — reads from state.json

state.iterations?.map((rec, idx) => ({
  n:             rec.n,              // header & dot label
  started_at:    rec.started_at,     // tooltip row
  ended_at:      rec.ended_at,       // tooltip row; null => active
  outcome:       rec.outcome,        // dot color mapping
                                     //   active (ended_at==null) -> teal
                                     //   revisited -> amber
                                     //   advanced -> teal-dark
                                     //   abandoned -> gray/50%
  triggered_by:  rec.triggered_by,   // tooltip row; also overrides
                                     //   outcome color for
                                     //   feedback_rollback -> orange
  feedback_scope:rec.feedback_scope, // chips under the tooltip
  hydrated:      !rec.started_at || !rec.ended_at && idx < iterations.length - 1,
                                     // dashed border + legacy-stripe backdrop
}))
